# Contributing Guidelines

## Project Development Approach

The Affordable Generative AI Chatbot for SME Restaurants project will be developed during Part B using an Agile/Scrum-inspired approach. Development activities will be organised into planned sprints, allowing continuous improvement, testing, and evaluation throughout the project lifecycle.

## Part B Development Process

The project will progress through the following stages:

### Sprint 1 — Requirements and Design
- Review and refine chatbot requirements.
- Finalise system architecture and chatbot workflow.
- Define user scenarios and testing criteria.

### Sprint 2 — Prototype Development
- Develop the chatbot prototype.
- Configure Generative AI components.
- Create the restaurant knowledge base.
- Implement customer enquiry workflows.

### Sprint 3 — Testing and Evaluation
- Test chatbot responses and accuracy.
- Evaluate usability and performance.
- Identify improvements based on feedback.

### Sprint 4 — Final Improvement and Documentation
- Apply improvements from testing outcomes.
- Complete technical documentation.
- Prepare final demonstration and project report.

## Version Control Practices

The project will use GitHub for version control and collaboration.

Development practices include:

- Maintaining clear commit messages.
- Tracking tasks through GitHub Issues and Project Boards.
- Documenting major design decisions.
- Reviewing changes before merging.

## Responsible AI Development

All project development activities will consider:

- AI accuracy and hallucination risks.
- User privacy protection.
- Human oversight for complex requests.
- Responsible use of Generative AI technologies.

The project will follow relevant guidelines including the NIST AI Risk Management Framework and Australian AI Ethics Principles.

## Documentation Standards

All major project changes should include updated documentation where required, including:

- Architecture diagrams
- Testing results
- Project decisions
- Technical documentation
